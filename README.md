Leviathan Dip — a tiered capitulation-dip buyer for cbBTC. It waits for a 60-minute log return below -2.0% with a green-bar bounce confirmation, buys 50% of cash, adds the rest if the dip deepens below -2.5%, then rides the recovery for 120 bars (hard stop 1.5%). Deterministic, standard library only, no network, no clock, no randomness. Dev window: +$4.78; walk-forward mean +$5.43 across 7 windows.
